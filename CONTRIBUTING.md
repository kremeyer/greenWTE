# Contributing to greenWTE

Thank you for your interest in contributing to greenWTE!

We welcome contributions in the form of bug reports, feature requests, and code contributions.
Feel free to open an issue or a pull request to the `dev` branch.
Make sure to run the pre-commit hooks and tests before submitting a pull request.
If you are adding substantial new functionality, please include appropriate tests and ideally update the documentation as well.

You can also reach out to @kremeyer via email for any questions or suggestions.
